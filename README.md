# Скиллы ИИмерсивного

Скиллы, которыми я сам монтирую ролики и веду канал [@art.immersive](https://youtube.com/@art.immersive). Не теория — то, что работает у меня в проде.

## Установка в Claude Code

```
/plugin marketplace add ArtCog/skills
/plugin install video-montage@artcog
```

Обновления прилетают сами — я пушу в этот репозиторий, у тебя обновляется.

## Что внутри

### `video-montage` — механический монтаж через ffmpeg

Резка пауз по **голосовой дорожке** (а не по миксу — это принципиально: демка со звуком игры больше не мешает резать), склейка сцен, субтитры по единому стандарту, оверлеи, PiP, цветокоррекция, финальный рендер под YouTube на NVENC.

Пороги внутри не выдуманы — выставлены на слух на реальных роликах и зафиксированы: `threshold=0.06`, `margin 0.12s/0.10s`. Не откатывать.

`SKILL.md` — каркас и решения. Детальные рецепты лежат в `references/` и подгружаются агентом только когда нужны, так что скилл не занимает контекст, пока не понадобится.
